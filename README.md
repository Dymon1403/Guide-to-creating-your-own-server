# 2.Начала начал
перед установкой ОС и софта, важно все серьезно подготовтить,настоятельно рекомендую сделать:
  масс чистка комплектующих, будь комп или ноут, просто надо, сервер должен работать всегда, с новой термухой он просто прослужит дольше, так вот, все продуть и собрать, на проц залить новую термуху ЕСЛИ КОМП:
  ARCTIC MX-4 / MX-6 - абсолютный топ по соотношению цена/качество.MX-4 максимально легко наносится, MX-6 чуть гуще, но лучше справляется, если чип сильно греется. Не сохнет годами.
  Noctua NT-H1 / NT-H2 - надёжная классика. Отличная теплопроводность, долго живучая, легко намазывается.
  Thermal Grizzly Hydronaut - если хочется выжать максимум по градусам. (Важно: Kryonaut от этой же фирмы брать не стоит - она быстро деградирует при температурах выше 80°C, а Hydronaut держится отлично).

# 2.1 Настройка BIOS/UEFI:

    Restore on AC Power Loss: Найди пункт Power Management -> AC Power Recovery (или аналогичный) и выставь Power On. Теперь, если дома моргнет свет, сервер автоматически включится сам при появлении питания. 
    Отключение лишнего: В BIOS отключи встроенный звук (Audio), Bluetooth и неиспользуемые порты, если они не нужны - это сэкономит пару ватт и уменьшит нагрев, что для сервака гуд

# 2.2 WIFI Ethernet
 сука забудь нахуй навсегда про какие там сети, ток мужской кабель, wifi дает нестабильность + в linux мне потом спасибо скажешь, все автоматом подхватывается. Дальше, заходим в настройки роутера(192.168.0.1 or 192.168.0.1 standart) найди раздел DHCP Server -> Static Lease / Address Reservation и там дай stable IP твоему серверу, чтобы он всегда был доступен по одному и тому же адресу.

# 3. ОС и Базовая настройка системы
# 3.1 Какой дистрибутив брать?

Забудь про десктопные системы с графическим окружением (GNOME, KDE и прочие графические оболочки). Серверу не нужен монитор и лишний жор оперативы.
    Debian / Ubuntu Server - классика. Железобетонная стабильность, миллион статей в инете под любую проблему.

    Void Linux / Alpine - выбор для ценителей минимализма. Быстрый старт, минимальное потребление ОЗУ (Void без systemd на runit жрет буквально 50-70 МБ оперативы в простое).

# 3.2 Сетевое поведение крышки (если сервер на Ноутбуке)

Чтобы ноут не уходил в сон при закрытии крышки, нужно жестко прописать поведение обработчика событий:

    В systemd (Debian/Ubuntu):
    Редактируем /etc/systemd/logind.conf:

``` bash
    HandleLidSwitch=ignore
    HandleLidSwitchExternalPower=ignore
```
   
    И применяем: sudo systemctl restart systemd-logind

    В runit / elogind (Void Linux):
    Редактируем /etc/elogind/logind.conf и выставляем те же параметры HandleLidSwitch=ignore.
